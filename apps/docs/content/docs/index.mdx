Billleaf follows the way work actually flows:

**Client → Quote → Contract → Project → Time → Invoice → Payment → Receipt**

Each step hands its details to the next, so you type things once: an accepted quote becomes a contract, a project or an invoice; tracked time becomes invoice lines; a payment produces a numbered receipt.
