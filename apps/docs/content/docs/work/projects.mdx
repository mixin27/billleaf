title: Projects and tasks
description: Organise work for a client, with a task board.
---

A project groups the work for one client (or internal work, with no client). Choose how it's billed:

- **Hourly** — tracked time is invoiced at an hourly rate. See [Rates and budgets](/docs/work/rates-and-budgets).
- **Fixed price** — a set amount, for example from an accepted quote.
- **Not billable** — internal or unpaid work.

## Tasks

Each project has a board with **To do**, **In progress** and **Done** columns. Add tasks, assign them to team members, give them due dates and move them between columns. Time can be tracked against a task.

## Status

Projects are **Active**, **On hold**, **Completed** or **Archived**. Archived projects are hidden from the timer and pickers. A project with tracked time can't be deleted — archive it instead.
