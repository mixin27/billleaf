title: Time tracking

## Tracking time

- **Timer** — type what you're working on, pick a project (and task), and press start. The timer keeps running across pages and shows in the sidebar. Starting a new timer stops the running one.
- **Manual entries** — add time afterwards with a start and end time, or a date and a duration.
- **Timesheet** — the weekly grid: one row per project and task, one column per day. Type hours into a cell to set that day's total.

Mark entries **billable** or not, and add **tags** (for example "meeting" or "revision") to group them in reports. Entries without a project are allowed but can't be invoiced.

## Reports

**Time → Reports** shows totals by project, client, member, tag, task or day for any period, with billable amounts (and cost and profit if you can see [rates](/docs/work/rates-and-budgets)). Switch between **Summary**, **Detailed** and **Weekly**, and export to CSV.

## Invoicing time

On an hourly project, **Invoice unbilled time** creates a draft invoice with one line per task and rate. Invoiced entries are locked; deleting the draft (or voiding the invoice) releases them again.

## Importing from Clockify

Export a **Detailed report** CSV from Clockify and upload it in **Time → Import**. You'll see a preview first: new clients, projects, tasks and tags it will create, and any rows it can't read. Importing the same file twice adds nothing twice.
