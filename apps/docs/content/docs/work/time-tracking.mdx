## Tracking time

- **Timer** — type what you're working on, pick a project (and task), and press start. The timer keeps running across pages and shows in the sidebar. Starting a new timer stops the running one.
- **Manual entries** — add time afterwards with a start and end time, or a date and a duration.
- **Calendar** — your week (or one day) hour by hour. See [The calendar](#the-calendar) below.
- **Timesheet** — the weekly grid: one row per project and task, one column per day. Type hours into a cell to set that day's total.

Mark entries **billable** or not, and add **tags** (for example "meeting" or "revision") to group them in reports. Entries without a project are allowed but can't be invoiced.

## Time rules

In **Settings → General → Time rules**, an owner or admin can set:

- **Rounding** — round each entry **up**, to the **nearest**, or **down** to 1, 5, 6, 10, 15, 30 or 60 minutes. It applies to invoices from time, project amounts and reports; the time you tracked stays exact. Each entry rounds on its own, so two 7-minute entries rounded up to 15 minutes bill 30 minutes. Reports have a **Rounded** checkbox to see exact time instead.
- **Lock time before** — a date. Time dated before it can't be added, changed or deleted by anyone (timer, calendar, timesheet, imports). Use it once a period is invoiced or closed. Move or clear the date to make changes. It can't be later than today.

## Favourites

Pin what you do often so you can start it in one click:

- Type a description (and pick a project, task, tags) in the timer, then press the **star**.
- Or open an entry's **⋯** menu and choose **Add to favourites**.

Favourites show under the timer. Click one to start it (it stops any running timer), or press **1** to **9** for the first nine. Use a favourite's **⋯** menu to move it left or right, or remove it. Favourites are yours alone; you can pin up to 12.

## Keyboard shortcuts

Single keys work anywhere you're not typing in a field. Press **?** to see them all.

| Key | Does |
| --- | --- |
| **S** | Start or stop the timer (on the Time page it jumps to "What are you working on?") |
| **1**–**9** | Start a favourite (Time page) |
| **N** | Log time for the last hour (Time page) |
| **←** / **→** | Previous / next week, or day (calendar and timesheet) |
| **T** | Back to today (calendar and timesheet) |
| **W** | Switch the calendar between week and day |
| **⌘K** / **Ctrl+K** | Command menu |
| **D** | Light or dark mode |

On the Team plan, weeks can need an approver's sign-off before they're invoiced. See [Timesheet approvals](/docs/work/timesheet-approvals).

## The calendar

Open **Time → Calendar** to see your own time laid out by hour, in the workspace's time zone.

- **Log time:** drag down over empty space (or click once for an hour), then fill in what you worked on.
- **Move:** drag a block to another time or day.
- **Change the length:** drag a block's bottom edge.
- **Edit or delete:** click a block.
- **Week or day:** switch with the buttons at the top right. Click a day's header to open just that day. Phones start in day view.

Time logged as a **duration only** (from the timesheet, or with a date and a duration) has no clock times, so it sits in the **No set time** row above the hours. Drag it onto the calendar to give it times, and it keeps its length.

Entries on an invoice show a lock and can't be moved. A running timer shows up to now; stop it before changing it.

## Reports

**Time → Reports** shows totals by project, client, member, tag, task or day for any period, with billable amounts (and cost and profit if you can see [rates](/docs/work/rates-and-budgets)). Switch between **Summary**, **Detailed** and **Weekly**, and export to CSV.

## Invoicing time

On an hourly project, **Invoice unbilled time** creates a draft invoice with one line per task and rate. Invoiced entries are locked; deleting the draft (or voiding the invoice) releases them again.

## Importing from Clockify, Toggl Track or Harvest

In **Time → Import** (needs permission to edit anyone's time), pick the app, then upload its CSV export:

| App | Where to export |
| --- | --- |
| **Clockify** | Reports → Detailed → Export → Save as CSV |
| **Toggl Track** | Reports → Detailed → Export → Download CSV |
| **Harvest** | Reports → Time → Detailed report → Export → CSV |

You'll see a preview first: how many entries, new clients, projects, tasks and tags it will create, who the time belongs to, and any rows it can't read. Importing the same file twice adds nothing twice.

- **People** are matched to members by email (Clockify, Toggl), or by name when the file has no email (Harvest; the name must be unique in the workspace). Anyone not matched is assigned to you.
- **Times** from Clockify and Toggl are read in the workspace's time zone. Harvest exports hours per day without clock times, so those entries show under **No set time** in the calendar until you drag them onto it.
- Rows in a [locked period](#time-rules) or an approved week are skipped and listed.
